# Dataset Information
This folder contains information about the dataset used in this project.
The original dataset can be downloaded from Kaggle.

## Dataset Source

This project uses the synthetic Credit Card Fraud Detection dataset published on Kaggle.

**[Click here to access and download the Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets/kartik2112/fraud-detection)**

## Dataset Files

The Kaggle dataset contains:

- `fraudTrain.csv`
- `fraudTest.csv`

## Download Instructions

1. Click the Kaggle dataset link above.
2. Sign in to your Kaggle account if required.
3. Download the dataset.
4. Extract the downloaded ZIP file.
5. Upload the required CSV file to Google Colab.

## Dataset Usage

The current notebook uses the uploaded dataset and creates its own stratified 80/20 training and testing split.

The separate `fraudTest.csv` file has not yet been used in the current model evaluation.

## Important Note

The original CSV dataset files are not included in this GitHub repository. Users can download them directly from Kaggle using the link provided above.
